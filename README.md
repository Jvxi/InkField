## 🎯 项目简介

<div align="center">

> 🚀 **面向网络小说作者的 AI 辅助写作工作台**
> 
> 支持从构思到成稿的全流程创作，严格模式下约束正文纯度、必写情节点与禁写内容
> 
> 让 AI 成为你的**创作助手**，而不是**替代者**

</div>

## 🌟 功能详解

<details>
<summary><b>📝 多页面工作流</b></summary>

<br/>

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  📚 书籍信息  │───▶│  ❓ 开书问卷  │───▶│  📋 大纲管理  │
└─────────────┘    └─────────────┘    └─────────────┘
                                              │
       ┌────────────────────────────────────────┘
       ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  👤 角色设定  │───▶│  🔗 伏笔管理  │───▶│  ✍️ 章节写作  │
└─────────────┘    └─────────────┘    └─────────────┘
```

- 每个环节独立页面，支持随时回溯修改
- 工作流进度可视化

</details>

<details>
<summary><b>🤖 AI 辅助写作</b></summary>

<br/>

| 功能 | 说明 |
|:---:|:---|
| 🌊 流式输出 | 实时预览 AI 生成内容 |
| 🔌 接口兼容 | 支持 OpenAI 兼容 API |
| 🔄 自动回退 | 未配置 Key 时使用规则模板 |
| ⏹️ 中途取消 | 随时停止生成 |

</details>

<details>
<summary><b>✅ 严格合规校验</b></summary>

<br/>

开启「严格正文模式」后，生成结果需同时满足：

- [x] 无元标签
- [x] 无"帮读者总结/故事线走向/下一章预告"等旁白话术
- [x] 大纲的必保留项、摘要、目标、冲突均需在正文中体现
- [x] 章节摘要/目的需有对应锚点
- [x] 不命中禁写项

> ⚠️ 未通过时草稿**不会**保存到章节

</details>

<details>
<summary><b>📚 发布平台支持</b></summary>

<br/>

| 平台 | 支持情况 |
|:---:|:---:|
| 🍅 番茄小说 | ✅ 完整支持 |
| 📖 起点中文网 | ✅ 完整支持 |
| 📱 QQ阅读 | ✅ 完整支持 |

- 平台规则自动注入提示词
- 针对不同平台优化生成策略

</details>
